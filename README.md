# Nobel Prize Visualization

本项目是《数据可视化》课程小组作业，主题为诺贝尔奖科学发现可视化。

## 项目主题

从发现到认可：诺奖科学家的职业阶段、关键论文影响积累与获奖延迟。

## 核心问题

1. 诺奖关键论文通常在科学家职业生涯的什么阶段出现？
2. 从关键论文发表到获奖，通常要等待多久？
3. 不同学科在获奖延迟和职业路径上是否存在差异？
4. 诺贝尔奖更像是对首次发现的奖励，还是对科学共识形成后的确认？
